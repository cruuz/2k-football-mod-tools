## Implementation and integration boundary

`mod_editor/core/nfl2k5_modern_naming.py` has pure status/apply, source-based
restoration, strict user-JSON validation/fallback selection, catalogue overrides,
source-verified and static previews, image status, and transactional image
application. It accepts only reviewed `.string_` geometry/length/digest and the
reviewed STRG wrapper/table. All owned spans must agree on retail/applied state;
mixed/foreign bytes and changed game placeholders refuse before mutation.

Original-source restoration copies only the owned original allocations and
repins the string section through the existing digest helper. It preserves
unrelated text and gameplay edits. The image adapter preflights both halves,
checks for intervening changes, writes through existing bounded APIs, performs
exact readback, and rolls back ordinary I/O failures. Build still owns copy and
atomic publication; crash/power-loss atomicity is not claimed.

`tools/string_table_inventory.py` needed a targeted NFL fix: the old parser
walked first-NUL boundaries and treated zero fill after a shorter fixed-span
edit as unreferenced extra strings. NFL now derives interior allocations from
distinct lookup targets, rejects overlapping/nonzero padding, and retains those
sizes during rebuild. APF's variable rebuild behavior is unchanged. The final
pool's trailing zero capacity cannot be inferred from pointers alone; it stays
the existing bounded trailer. This patch owns interior pool 3, not that tail.

`mod_editor/gui/modern_naming_panel_qt.py` and a narrow Text-only insertion in
`text_rosters_panel.py` render the complete review and MyCareer contract labels.
The static fallback explicitly says source and Build are not connected. The
protected Studio facade callback and Build option are specified in `WIRING.md`,
including off/on/off behavior, manual conflict prevention and stale JSON refusal.

No runtime code, allocator budget, cave, reservation or save schema is added.
Both executable gates compose the name pass before/after all allocator owners.
The memory-write gate also had a pre-existing Senior Bowl test error:
`image` and `absolute_writes` were undefined in that test. Its missing local
oracle import/construction is repaired here so the required gate can execute.

The adjacent team-name regression also exposed a legacy whole-pack header read
in `OuterImage._open_loose`. It used `index.read_bytes()[:HEADER_SIZE]`; this
is now a context-managed `read(HEADER_SIZE)`. A regression forbids `Path.read_bytes`
