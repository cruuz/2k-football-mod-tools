## PROVED in this session

The new native suite contains **410 reaction invocations**, **96 initializer
slices** and **33 movement-latch slices**. Every invocation has a maximum of
1,000 instructions and an asserted stop address. XBE pages use the permission
union of their actual section descriptors. No game is booted or rendered.

1. **Effective facing includes the animation object's rotation.** The complete
   native `0x217AE0` chain adds `[[P+0x18]+0x50]` to the orientation obtained
   from `[[P+0x14]+0x34]`. It calls `0x217AB0`, quaternion-vector operation
   `0x3CA1E0` and quaternion multiply `0x3CA150`, then bearing `0x210B0`.
   Twenty-four heading/rotation fixtures cover wraparound and quarter turns;
   expected signed-angle results agree within one native approximation unit.
   This corrects any implementation assumption that setting the AI's preferred
   heading, or reading only the body heading, establishes effective facing.
2. **The existing native facing contribution is sufficient to change the
   tested response gate.** With Coverage 0.5 and motion context 0.8, thresholds
   are approximately 0.5125 at 0/45 degrees, 0.3125 at 90 degrees, 0.2625 at
   the stored 20,935-unit knot, and 0.2125 at 180 degrees. Both side tables are
   exercised. Controlled seeds run through real `0x48B90`/`0x48B50`; samples
   0.001 below/above each threshold take the expected success/failure branch.
   Each invocation draws once and never reaches the catch cave.
3. **The initializer cap does not add a response change.** Cover 3 depth
   fixtures at 1, 5, 6, 6.999, 7 and 10 yards, both field directions and three
   headings give identical retail/capped reaction results for supplied ball
   destinations labelled go, curl and comeback snapshots. These are isolated
   destination snapshots, not executed receivers or full coverage traces.
4. **Cover 2 and four-deep controls preserve the known scope.** FS/SS identities
   16/17 in deep modes, flat corners in modes 5/6, and off corners preserve
   native initializer actor memory. Shallow corners in ordinary modes 9/10
   still receive the existing 0.84 cap. All these controls preserve response
   results for identical effective-facing inputs. This does not prove all
   four defenders' full-play coverage behavior or modern match quarters.
5. **Coverage and catch remain separate.** In the combined cap/Spy/Coverage
   fixture, Coverage 0/0.5/1 changes only its existing slider contribution.
   The neutral 0.5 cases remain identical to retail. Adding the catch patch
   produces identical reaction thresholds, seeded rolls and gate outcomes.
   Runtime writes in these reaction fixtures are confined to the stack and
   the native 448-byte RNG record; no new persistent state exists.
6. **A later low throttle does not necessarily undo running state.** Native
   helper `0x1A4170` sets the latch at 0.91 and 1.0. An inherited latch stays
   set at 0.5/0.84/0.9 with reset 0. It also stays set at 0.35 with reset 0;
   reset 1 and 0.35 clears it, while equality at 0.36 does not. Retail, cap and
   the combined owner image agree. The slice stops before navigation call
   `0x1A4246`; it proves the latch branch, not the ensuing movement.
7. **Callback ownership and both existing installation orders are exact.**
   With the complete pair/coverage request union preallocated, Spy then cap
   and cap then Spy produce identical bytes for caps 0.6 and 0.84. Both
   recognize and replay. The manifest assigns the callback prologues to Spy
   alone and the initial depth call to zone drop alone. Mixed or foreign
   callback/body/rotation/reaction bytes refuse even with fresh section hashes
   or an allocator-sealed foreign code body.

The effective-facing test also verifies the return stack, the deeper x87
sentinel stack depth and visits to all expected native geometry/RNG routines.
It does not add a general ABI or arbitrary pending-FPU-exception claim beyond
the shipped owner's existing proofs.

## Known gaps and delivery boundary

No relevant-receiver selection/crossing identity, thirds-only bail discriminator,
press adjustment lifecycle, complete pass-release/turnover path, sustained
effective-facing control, new detour broker or new feature-state lifecycle is
certified here. Spy's guarded loss-of-QB-possession path does not by itself
certify those corner-specific policies. No callback is shared with an invented
owner, no retail cave is used, and no runtime data is placed in `.text`.

The native response routine is invoked directly in artificial actor memory;
reaching it in a live play and converting its result into a break, deflection,
catch or interception remain unproved. The new tests deliberately avoid
claiming full routes from isolated geometry snapshots. Loader behavior, rendered
bail/backpedal/head direction and all gameplay efficacy remain unwitnessed.
