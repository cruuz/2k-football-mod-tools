# Install SOFTDRINK 2K28 in 5 steps

1. Download **2K5 Mod Studio** and one **SOFTDRINK 2K28 game patch**. On Windows, choose the 2K5 Studio `Setup.exe`. On Linux or macOS, download and extract the 2K5 Studio `.tar.gz`. On Linux, run `./2K5-Mod-Studio.sh --setup` once, then open `./2K5-Mod-Studio.sh`. On macOS, right-click `2K5-Mod-Studio.command` in Finder and choose **Open**. If prompted for Python, install 3.11, 3.12 or 3.13 and open the launcher again. For the standard game, choose `SOFTDRINK-2K28-v0.10.2k5patch`. Leave the game patch in that format. [Download Studio](https://github.com/cruuz/2k-football-mod-tools/releases/tag/beta-81) · [Download the game patch](https://github.com/cruuz/softdrink-2k28/releases/tag/v0.10)
2. Open Studio. On **Getting Started**, press **Install SOFTDRINK 2K28…** (the same button is on **Build & Share → Install & Share**).
3. Choose your **unmodified ESPN NFL 2K5 USA Xbox disc image**, then the **`.2k5patch` file itself**. Use the original image for each update.
4. Choose where to save the **new image**, such as `SOFTDRINK 2K28.xiso.iso`. Wait for **Disc ready**.
5. In xemu, choose **Machine → Load Disc** and select that **new image**, or click **Play latest disc in xemu** in Studio. In the game, **load the disc roster and start a fresh franchise**. Existing franchises keep their saved rosters.

For the **standard pack**, choose **128 MiB** in xemu and use the tested **COMPLEX 4627** Flash ROM. For the **experimental 64 MB pack**, choose **64 MiB**. After a memory or BIOS change, close xemu completely and reopen it. A startup message on the standard pack gives the detected kernel number when it needs a different BIOS. [Recommended xemu settings](recommended_xemu_settings.md) · [Startup message guide](2k5_mod_studio_faq.md)

To report a freeze, open **Help → Check my SOFTDRINK disc…** and select your finished game. Include its result, the pack version and memory variant, your platform and renderer, the in-game screen or play, and whether it happens in a fresh franchise or only after loading a save. For a custom build, include the Studio build receipt. On Steam Deck, the same xemu settings apply. PC and Android ports and XBased use different runtimes. Identify the runtime when reporting an issue.
