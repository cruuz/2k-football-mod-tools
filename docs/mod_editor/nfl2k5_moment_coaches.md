# Historical Anniversary coaches

The Studio runs nfl2k5_moment_coaches before the period-field pass. The source disc supplies the preserved models. A versioned 172-byte extension follows each SITU objective string terminator; visible text and situation values stay intact. At selection, a 512-byte hook copies each chosen coach and both names into private 256-byte slots before SITU unloads. The new allocations use the remaining promoted MyCareer code footprint and the legacy RW tail without moving earlier owners. The main roster and modern model resources remain intact.

All 51 physical rows and both real head coaches. Seasons below are actual game seasons, not the retail template years. The game links are references for the game and staff; native retail roster/model identity was checked separately. Fifteen confirmed retail models cover 32 team appearances. The other 70 appearances need likeness art. Bill Parcells is included in the art list because retail c07 is Dallas Coach, not an established Parcells likeness.

## Art follow-up

No faces or models were authored. Correct names are installed for these appearances; their placeholder bodies remain. Each new likeness needs its own archive and a catalog mapping. Preserve modern cNN archives and the c60..c89 retail aliases.

Technical contract: coach bundle SCNE chunk 0, scene coach; named shapes coachBodyGrp1, coachLodGrp1 and coachHeadGrp1. The face atlas is headShader1, P8 256x128, full mip chain and existing model UV layout. The full face and scalp need review; no rectangular UV subsection has been established as sufficient. Preserve the skeleton and animation contracts. The model filename and source mesh must be chosen by the art job after inspection. The game binds the team shirt, jacket, cap and logo textures at runtime. Use the linked game/season to choose period reference photographs.
