# Code of conduct

This is a small project about modding two football games from 2004 and 2007. The
standard here is short.

## Expected

- **Be decent to people.** Harassment, personal attacks, and demeaning comments
  about anyone — including about someone's skill level, hardware, platform or
  choice of emulator — are not welcome.
- **Assume good faith.** Most confusing behaviour is someone learning, not
  someone being difficult. The first PS2 contribution arrived opened against the
  wrong repository; the useful response was to explain how to retarget it.
- **Be precise instead of certain.** "I saw X on build Y, here's the file" beats
  a confident guess. It is fine not to know something.
- **Say what you did not verify.** Reporting the limits of your own testing is a
  contribution, not an admission.

## Not welcome

- Harassment, sustained disruption, or unwelcome personal attention.
- Publishing someone's private information.
- **Sharing game files, ISOs, ROMs, or links to them, anywhere in this project.**
  Issues, pull requests, comments — anywhere. This project ships no game data,
  every user brings their own legally obtained copy, and that boundary is not
  negotiable. It protects the project's ability to exist.

## Scope

Applies in this repository — issues, pull requests, discussions, commits — and
anywhere someone is representing the project.

## Enforcement

Report by opening a private security advisory or contacting the maintainer
directly rather than in a public thread. Reports are handled discreetly.

Responses are proportionate: usually a clarifying reply, sometimes an edit or a
locked thread, and a ban only for deliberate or repeated behaviour. Anything
involving game files or links to them is removed on sight, without prejudice —
people often do not realise it is a problem.
