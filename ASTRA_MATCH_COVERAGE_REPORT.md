# Astra match coverage report

**EXPERIMENTAL / UNWITNESSED.** Delivered a complete census of explicit native
coverage exchanges, 105 offscreen retail formation diagrams, five authored-call
diagrams, named Rules library bundles, searchable Info documentation and the
installable `data/playbooks/softdrink_match_coverage.2k5book` pack.

**Full modern Rip/Liz, quarters-match and Palms receiver keys are not implemented.**
The pack ships five explicitly labelled experiments using the game's established
geometric exchange mechanism, plus the native Cover 1 robber shape. Calling those
experiments complete modern schemes would exceed the evidence. This is a material
limit of the requested modern coverage scope, not a promised future toggle.

## Zone Double Steal supports the expert's description

Ravens **BAL, 3-4 f25, Zone Double Steal p14** has these stored pairs:

* **CB2 slot 9 -> FS slot 7** on the offense's right.
* **CB slot 10 -> SS slot 8** on the offense's left.

The corner starts in man coverage. Native mask 7 tests the receiver's predicted
position (current position plus **0.2 seconds** of velocity), beyond the defender
and at least **15 yards downfield**. On that condition the corner signals the
safety and changes to a zone at **X +/-15, depth 12 yards**. The safety begins
with a **15-yard zone landmark** and changes to man when its signal is consumed.
A deep streak satisfies this geometric rule; the code does not inspect a route
name, so other sufficiently deep routes can also qualify. All ordinary native
receiver, ball and play-state gates still apply.

![Ravens Zone Double Steal](docs/mod_editor/match_coverage/BAL-p014-f25.png)

**PROVED:** these bytes and consumer dataflow agree with the supplied expert
account. **HYPOTHESIS:** exact live assignment timing, target pickup and the
breadth of the expert's "everywhere except streaks" statement. The expert's
reported play test is supplied evidence, not a witness performed here.

The retail XBE SHA-256 is
`73105b17a3161c546fea792a1c84ce37f9966a67c416f474cdbfab74b911a4a9`.
[Native evidence pins](docs/mod_editor/match_coverage/evidence.json) identify
complete function bytes and Ghidra blocks for `0x0019FA10` (boundary),
`0x001A2E70` (signal and man continuation), `0x001A5090` (zone signal consumer),
`0x001A5BC0` / `0x001A6220` (initializers) and `0x001A05B0` (other native exits).
The boundary table is identity 0..15. Masks 13/14 test lateral crossings, with
no depth trigger. No emulator, GUI display, audio or network was used.
