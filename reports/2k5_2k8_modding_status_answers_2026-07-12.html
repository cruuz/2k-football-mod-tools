NFL 2K5 / APF 2K8 Modding Status

Answers to the five implementation questions · Evidence snapshot: July 13, 2026
Current closeout: The normative NFL and APF static-SCNE specifications are now machine-readable, and each title has one independently verified, fail-closed same-count stadium-position write-back witness. APF also has one fixed-footprint topology writer. NFL's pinned group36 edit has now crossed the runtime gate: paired control/expanded diagnostic runs deterministically loaded s42nd.iff in xemu, and the authored replacement rendered as a giant wall that is absent from the retail-geometry control. This is one fixed-footprint xemu witness—not a general edited-glTF importer, original-hardware proof, or production-ready disc path. A separate NFL upper_deck writer now closes an offline 12-to-8/4 synchronized source-subset count path with independent whole-volume verification; its runtime behavior remains untested. Full-game decompilation remains deferred.

1. Mesh write-back status

The first real read → edit → write → independently verify loop is now closed in both titles, for one pinned four-vertex stadium target each. APF additionally has one independently verified same-count index-strip rewrite. NFL now also has one target-specific static changed-count loop for source-derived 12-to-8/4 records. There is still no general edited-glTF → SCNE importer.

Proved read side

  • NFL 2K5: all 4,616 SCNE resources and 54,966 shapes parse. Position streams and all 276,642 NV2A topology streams are bounded and decoded.
  • APF 2K8: all 1,303 SCNE resources and 13,006 mesh nodes parse. Three position encodings, vertex declarations, streams, and BE16/BE32 indices are understood.
  • Both games have extensive static position/topology export to glTF.

Proved write side

  • NFL 2K5: stadium/group36, four little-endian FLOAT3 positions. A no-op reproduces the complete 634,941,440-byte volume exactly. The changed witness differs only in the 48-byte decoded position span; its recompressed bytes remain inside the original chunk, preserve the fixed 16-byte opaque tail, and pass a standalone stdlib verifier. The verified native span has also been transplanted into a layout-identical copied XISO; full-disc comparison proves that only the authorized 908,912-byte outer span changed. Later paired diagnostic runs used the same Super Bowl 2006 / Night / Clear route and deterministic replay-camera sequence. Both reached Ford Field; only the expanded build rendered the independently authored wall. This proves target load and visible geometry for this exact four-vertex fixture in xemu. The selector and forced-night diagnostic shims refresh XBE section digests but do not preserve the retail RSA-signed executable chain, so hardware and production claims remain false. Separately, shape 1 upper_deck now has a copied-volume writer for logical counts 8 and 4. It copies complete synchronized 12-byte position and 10-byte attribute/selector records from the pinned 12-record source, updates the two coupled count controls, preserves both physical stream tails, and passes a standard-library-only verifier that independently reconstructs the whole decoded SCNE and copied volume. The 8-vertex result changes only the two decoded count bytes; the nonidentity 4-record result changes 64 decoded bytes and yields two nondegenerate triangles. Neither changed-count output has a runtime witness.
  • APF 2K8: outer 14 / stadium / node 17 polySurface19930, four big-endian FLOAT3 position lanes inside a 24-byte interleaved stream. A no-op reproduces the complete 1,140,850,688-byte 1A volume exactly. The +1/+2/+3 XYZ witness rebuilds IFF/H7A, changes only stadium DRAM part 0, and preserves all 12 non-target parts. A separate fixed-footprint writer can permute the node's existing four BE16 strip indices: its changed witness alters only 2 of the authorized 8 decoded index bytes, leaves the draw record untouched, and independently decodes to exactly two nondegenerate triangles.

The same-count position recipes reject changed counts, topology, declarations, non-finite or silently rounded values, allocation overflow, source aliases, existing outputs, and unsafe path publication. The dedicated upper_deck recipe admits only 4 or 8 distinct source-record IDs and no external position or attribute values. The APF topology profile permits only a duplicate-free permutation of the same four vertex ordinals. General changed topology still requires command/index generation, pointer relocation, and broader archive reconstruction.

Static stadium geometry is materially closer than gameplay helmet shells. One pinned NFL four-vertex deformation is now visibly proved in xemu, but arbitrary topology, bounds, materials, semantic attachment/ownership, catalog-wide routing, and hardware acceptance remain unproved. NFL helmet geometry is embedded in a skinned/morphed hi_head; APF helmet_00 also carries blend indices and weights. Narrow same-count stadium deformation and one APF same-footprint strip rewrite are proved; arbitrary stadium conformance, NFL topology generation, and gameplay helmet-shell import remain substantially farther away. For NFL's 12-vertex static upper_deck, the archive writer and independent verifier now close 8/4-record source-subset output inside the fixed slot, but no runtime witness, external-value authoring, bounds/culling ownership, or other-target authorization exists.

2. Scorebug / HUD rendering facts

NFL runtime ownership has been touched. The material binder 0x000FC1A0, initializer 0x000FCCD0, and update/draw body 0x000FCE70 are mapped. score_buga and shield_espn have positive live xemu witnesses.

Position is not one proved editable scalar. SCNE stores local geometry, but the NFL update/draw path performs state-dependent transform-like writes, accumulates offsets, changes flags, and animates values. Final position and visibility are runtime-composed. APF similarly composes seven separate scorebug SCNE components, but its corresponding update/position owner is not yet mapped.

No safe-area or cross-presentation location assumption is proved. Moving raw geometry could desynchronize text/logo anchors or be overwritten, but that failure has not yet been witnessed. The safe next test is transform-write watchpoints followed by a copied-SCNE position experiment across gameplay, replay, and lower-third states.

3. Catch/drop formula

The final catch-versus-drop formula has not been located in either executable. No single threshold or drop-rate constant is proved.

  • Both games have exact Human/CPU Catching sliders from 0.0 to 1.0 in 0.025 increments.
  • NFL has exact Catching globals and an aggregate routine consuming all 18 Human/CPU controls, but it is not the final outcome branch.
  • APF editable Catching values reach runtime copies; recovered direct references are writes rather than the final gameplay read.
  • Even monotonic slider polarity in every gameplay situation remains unproved.

Drops being emergent from ratings, timing, contact, animation, and RNG is plausible but not established; a later single comparison could still exist. The next safe experiment is a Catching-value watchpoint during controlled identical pass attempts, followed through RNG and the final outcome branch.

4. Fixed-allocation reality for meshes

Current safe tools must treat archive extents as fixed. That does not prove an immutable engine-level per-mesh slot; it means a size-changing repacker is not available.

TargetMeasured allocation condition
NFL proved group36 targetThe decoded vertex count and 48-byte position span are fixed. Recompressed VC-LZ consumption may not cross the retail 908,864-byte boundary or the fixed final 16-byte tail. A deliberately high-entropy replacement is rejected.

Without relayout, growth mechanically overwrites the next resource or exceeds the indexed outer extent. A conformer must reject it. Loader refusal/crash behavior for an intentionally over-budget mesh is unknown. The Xbox 64 MB runtime ceiling cannot be inferred from these disc allocations; complete live stadium memory ownership has not been measured.

Current machine-readable foundation

The primary mesh contracts are reports/specs/nfl2k5_xbox_static_scne.v1.json and reports/specs/apf2k8_scne_static_serializer.v1.json. The APF draw/topology contract is reports/specs/apf2k8_scne_draw_topology.v1.json; NFL's first changed-count boundary is reports/specs/nfl2k5_upper_deck_changed_count_boundary.v1.json, while its later implemented offline result is pinned by reports/specs/nfl2k5_upper_deck_source_subset_writeback_closure.v1.json; exact disc transport is specified by reports/specs/nfl2k5_group36_geometry_xiso_transport.v1.json. The exact runtime route is split into machine-readable s42 dispatch, Quick Game visibility, and forced-night diagnostic specifications. Its closed result schema is reports/specs/nfl2k5_group36_xemu_runtime_result.v2.schema.json, and the scoped positive result is reports/assets/nfl2k5_group36_s42_xemu_runtime_positive.v2.json; it explicitly keeps pixel alignment and the older protocol's exact-frame branch false while recording the repeated end-zone-facing camera sequence, unique authored wall, and independent payload proof. It remains separate from the older selector-skip negative. Each artifact keeps the still-false general-writer, signed-retail-chain, original-hardware, and production claims explicit. Recipe schemas are machine-readable and contain no retail geometry. The next mesh step is catalog and semantic ownership generalization, followed by a fail-closed static conformer; arbitrary edited-glTF import, auto-decimation, materials/UVs, collision, LODs, helmets, and skinned write-back are not yet implemented.
