## Wired in the Rosters tab

`RosterEditorPanel.load_save(path)` → after the roster document loads, `_franchise_summary(container.savegame)`
runs `nfl2k5_franchise_save.is_franchise_save` and, for a franchise, `FranchiseSave.summary()`; `_show_franchise`
fills `self.franchise_label` (object name `franchise_summary`) with year / stage / week / user team + coach
record / salary cap / grid games played / injured reserve.  `load_document` hides it again, so a disc or a
roster body never shows a stale card.  It is wrapped in `try/except` and can only ever hide itself.
Nothing writes: the panel's save path (`rr.save_document`) already copies every non-arena byte verbatim,
so franchise saves edited in the Rosters tab keep their season blocks intact.

## Hooks for the next UI step (not built — all read/write surface exists in the core module)

* **Franchise card → tab.**  `FranchiseSave.summary()` already returns everything a card needs; a tab would add:
  `set_display_year`, `set_salary_cap`, `set_user_control(team, flag)` (three spin/toggle rows), the grid as a
  22-row table (`games(rows=[r])`, `set_game(row, slot, …)` refuses played cells unless `allow_played`), the
  coach editor (`coaches()`, `set_coach_field(index, name, value)` with `COACH_FIELDS`, `COACH_RATINGS`,
  `COACH_TENDENCIES`), and IR (`injured_reserve()`, `place_on_injured_reserve(team, player_index)`,
  `activate_from_injured_reserve`).  Write with `FranchiseSave.write(target)` (re-signed copy).
* **Sharing bytes with the roster document.**  `FranchiseSave.roster` parses a `RosterDocument` over the ORIGINAL
  bytes; if a tab edits both, apply roster edits first (`document.to_body()`), then construct
  `FranchiseSave(edited_bytes)` for the franchise edits, or the other way round — the two never overlap except
  for `place_on_injured_reserve`, which edits the team pointer list inside the arena.
* **Build tab**: nothing to add; saves are not disc patches.

## Fixture policy

Private saves live in `~/Desktop/2K5-8 Editors/save_fixtures/<uid>-<name>/UDATA/53450030/<uid>/…`
(`CATALOGUE.md` there is generated by the tool).  Tests skip with the exact path when absent; never commit
the bytes.  `NFL2K5_SAVE_FIXTURES` overrides the folder; `NFL2K5_XEMU_IMAGE` (a COPY of the qcow2/raw)
enables the real-image listing test.
