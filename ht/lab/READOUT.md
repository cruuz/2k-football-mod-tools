# Main-only historic smoke check

**DESIGN:** Rebuild with `candidate_B_ht_requested.json` under the build folder, using the composed phase 2 stack and `historic_rosters_2026=true`. The offline proof disc is deleted after inspection. This script reads the supplied disc and its `.build.json` receipt; it does not build, modify or delete a disc. It requires the enabled roster option and an exact disc size/hash match.

**DESIGN:** Run `bash ht/lab/ht_smoke_candB.sh DISC BUILD_RECEIPT NEW_LAB_DIR`. The two routes are 49ers '81 home versus current Giants, then 49ers '81 home versus Giants '90. The historic selections should load their compact `HTS-` season resources. The driver holds the shared xemu lock, uses isolated configuration and the existing copy-on-write disk setup, and makes no automatic game retries.

**DESIGN:** At the coin toss, capture readable team names and captain names. Compare names, numbers and positions with `ht/evidence/phase2_worksheets.csv` and the matching team in `data/nfl2k5_historic_rosters/manifest.json`. Confirm the compact roster count against `ht/PHASE2_ROSTERS.md`. Capture close and distant historic helmets and masks, alongside a modern player in the mixed game. Historic Standard shell and masks 0 through 11 should retain their retail geometry. The current side should use its candidate B modern equipment. Compare screenshots, not only equipment bytes.

**DESIGN:** After coin-toss detection the driver presses START and opens a four-minute operator capture window. In a second terminal or tool call, append one button per line to the printed `card-commands.txt` path. Allowed buttons: UP, DOWN, LEFT, RIGHT, A, B, X, Y, START, LT, RT. Inspect each resulting `screens/card-*.png` before the next input. Navigate the game's visible pause/team roster or depth-chart menu to a historic player card. The exact menu route has not been witnessed, so the script does not guess one. If the card is only reachable outside the match, record that limitation and capture it in the team-management flow afterward.

**DESIGN:** Capture at least one historic player card per historic side. Append `NOTE visible name; number; position; helmet/mask observations` and then `DONE`. For example, `printf '%s\n' DOWN >> RUN/card-commands.txt` sends one down pulse. A NOTE is an operator observation, not an automatic assertion. Timeouts retain all evidence and leave review pending.

**DESIGN:** Save a review JSON with each item marked pass/fail/unwitnessed and screenshot paths: mixed coin names, mixed historic card, classic close helmet, classic distant mask, current modern helmet, historic-pair coin names, both historic cards, kickoff/play. The driver records coin-toss outcome separately and never marks visual review passed. Also witness one Practice start and one First Person Football start with historic selections through their visible menus. Those two mode starts currently have native selection proof only.

**DESIGN:** If the game crashes, freezes, or xemu exits, retain logs and screenshots and stop. A harness gate may be retried once after main identifies its cause, using a fresh lab directory. No xemu run was made by ht.
