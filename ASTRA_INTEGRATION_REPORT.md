## Handoff deviations

The proposed Coverage Geometry row had no backend command and used a direct
test path the strict registry parser does not recognize. A real receipt CLI
was added. New rows use the packaged runtime gate as their public validation
entry point; the full standalone tests remain development gates. Evidence
paths referring to another branch's `ASTRA_REPORT.md` were replaced by the
released wave guide, preserving the offline/UNWITNESSED limits and evidence
validation without shipping private research files.

The generic action-parity gate previously required every one-shot output to
contain the word "copied". Copy builders retain that rule; the new patch export
has an explicit stricter contract pinning its writer, authored TOML output,
Export action, absent replacement method and UNWITNESSED status.

The original full 46-pair project staged successfully, but its first Build
refused an over-allocation crest before creating an output folder. A per-pair
fixed-allocation pass is running to retain the largest fitting subset without
changing image content, reallocating packs or weakening the writer.
